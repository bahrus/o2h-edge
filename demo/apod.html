Astronomy Picture of the Day

NASA's APOD feed (science.nasa.gov/wp-json/wp/v2/apod-basic), rendered as HTML by o2h-edge and finished on this page.

The API also lists date_from / date_to, but it rejects every date format tried (ISO dates, compact dates, US and European orders, timestamps), so they're left out. per_page is capped at 25 by the API.

How it works: this page stores a record (its tree config and pipes, prepared by o2h's prepareO2HRecord) with the worker, then asks it to call the API and render the JSON. The worker renders what it can: the dates and the image / video badge come from data pipes, which run there. The explanations and credits need a function pipe (HTML to plain text), which can't reach the worker, so they arrive marked pending (hidden), and this page fills them in while hydrating (adopt: 'pending').
