Transforms

Every transform stored in an o2h-edge worker. Open one to see its JSON.

The list comes from GET /transforms, which needs the admin token (the worker's LIST_TOKEN secret) everywhere but localhost. The token is kept for this tab only (sessionStorage). Each transform's JSON comes from GET /transforms/<key>, when it's opened. Copy raw copies it exactly as stored: the JSON its key is the hash of, so storing the copy elsewhere gives the same key. The summary lists the data fields a transform reads.
